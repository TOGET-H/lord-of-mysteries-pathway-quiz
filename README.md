# 灰雾来信 · 非凡途径测试

纯静态中文网页小游戏，无第三方依赖，无 API 密钥。覆盖 22 条标准途径，包含 16 道原创情境题、可回退修改的答案、前三途径共鸣指数及具体答题证据。

## 本地试玩

直接双击 `dist/index.html` 即可离线运行。也可以在此目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后访问 http://127.0.0.1:4173/ 。

## 内容与评分

- `dist/data.js`：题库、22 条途径的序列 9 名称、描述、16 位偏好配置，以及纯函数 `rankPathways`。
- 每题首选 4 分，相关选项 1 分，其余 0 分。总分除以 64 后换算为整数共鸣指数。所有题等权。
- 总分相同时优先完全吻合题数；再相同则按固定档案顺序展示，页面提示并列，不随机制造唯一答案。
- 这是基于原作设定启发的娱乐测试，不是官方性格分类、心理测量、概率预测或道德评价。符号为装饰，不代表官方途径标志。
- 答案只存在页面内存中，刷新后清空，不使用数据库、统计脚本或浏览器存储。
- `dist/app.js`：界面状态、前进/后退、结果解释与可选 WebMCP 工具。普通浏览器不支持 WebMCP 时不影响游戏。
- `dist/style.css`：桌面与手机响应式样式，支持键盘焦点与减少动画偏好。
- `dist/lore.js` 与 `dist/lore.css`：结果页底部的 22 条途径档案，包含能力脉络、关联神明或代表人物、历史背景及原创寄语。神明身份与历史默认展开，可手动收起，并提示第一部剧透；寄语不是原作引文或角色原话。
- `dist/rituals.js`：成神仪式。当前包含愚者、错误、门、空想家、红祭司、黑皇帝的核心摘要，其余途径显示「完整仪式条件待核实」。摘要并非完整配方，尚未完成原文章节级核验；不能把未核实状态理解成原作确定未公开。

## 验证

```powershell
node --check dist/data.js
node --check dist/app.js
node verify.cjs
```

验证所有 22 条途径均可独立成为最高分、输入验证、分数边界与确定性。
